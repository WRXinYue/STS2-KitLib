Main-menu mod list and settings for Slay the Spire 2. Complements the official mod manager; it does not replace it.

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3793495384]Steam Workshop[/url]

[quote]
[b]Note:[/b] Split out of KitLib in [b]0.40.0[/b]. Subscribe separately; KitLib ≥0.40.0 no longer ships this panel.
[/quote]

[h3]Requirements[/h3]

[list]
[*][b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747619669]KitLib[/url][/b] ≥0.40.0 (required)
[*][b]STS2-RitsuLib[/b] (optional) — when loaded, each mod's Ritsu-registered settings pages appear in this panel
[*][b]KitDevTools[/b] (optional) — Harmony patch counts and the inspect report; Progress protection page
[/list]

Disable [b]KitModPanel[/b] in the game's mod list to turn the Mods UI off completely.

[h3]Open[/h3]

[list]
[*]Main menu [b]Mods[/b] overlay
[*]Settings → General → KitLib entry
[*]Configurable hotkey (KitLib → Hotkeys)
[/list]

Controller: cycle mods in the sidebar; LB / RB switch settings pages.

[h3]Mod list[/h3]

[list]
[*]Official scan: enable / disable (restart to apply). Read-only during a run
[*]Load status, version, Workshop vs local, install size
[*]Click the source chip to open the install folder
[*]Duplicate local override called out in the list
[/list]

[h3]Settings[/h3]

[list]
[*][b]RitsuLib mods[/b] — same pages those mods register with STS2-RitsuLib, hosted in this shell (no RitsuLib → list still works; those pages are skipped)
[*][b]KitLib[/b] — General (theme / normal-run / rail), Progress protection, Performance overlay, Hotkeys
[*]Other mods can register KitLib-native pages the same way
[/list]

CJK uses the game's locale fonts (Wine / Linux included).
